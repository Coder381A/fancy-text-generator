# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-05
### Added
- 50+ Unicode font styles & typography transformations.
- Zalgo / Glitch diacritics generator with variable intensity controls.
- Aesthetic decorator builder (frames, wings, kaomoji borders, ribbons).
- Responsive, accessible Web UI with Instant Search, Category Filter, and Theme switcher (Dark, Light, Cyberpunk, Nord).
- Real-time text metrics analyzer (UTF-8 byte length, grapheme clusters, word count).
- One-click copy with accessible visual toast feedback.
- URL Hash state sharing for customized text presets.
- Zero-dependency TypeScript core engine compatible with ESM, Node, and browser runtimes.
- GitHub Actions CI matrix and automated GitHub Pages deployment workflow.
