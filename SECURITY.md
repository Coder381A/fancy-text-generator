# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Fancy Text Generator, please do NOT open a public issue. Instead, send an email to the maintainers or report it through GitHub Security Advisories.

We will review the vulnerability, issue a fix, and release a patch promptly.
